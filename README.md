# 搜打撤 · STS2-ExtractionRun

语言 / Languages：中文 | [English](README_EN.md)

《杀戮尖塔 2》(Slay the Spire 2) 新增游戏模式——搜打撤模式。基于 [RitsuLib](https://github.com/BAKAOLC/STS2-RitsuLib) 框架构建。

> 进塔前，从你的仓库里挑好装备带走；打通了，把战利品带回家；倒在了路上，装备也就永远留在了那里。

---

## 玩法

每个存档槽拥有一个独立的持久**仓库**。开跑之前，在主菜单的「搜打撤」入口进入仓库界面：

1. 从仓库中挑选卡牌、遗物、药水与金币，组成你的**携带装备**——卡牌与遗物占用共享的**背包容量**（默认 15 格，见「背包容量」）。
2. 开始搜打撤。携带的牌组替换默认初始牌组，携带的物品会**从仓库中扣除**。
3. **通关 = 撤离成功**：本局最终牌组、遗物、药水与金币全部存入仓库。
4. **死亡或中途放弃 = 撤离失败**：携带进局的装备全部损失。

首次启用时，仓库会自动发放全部初始与普通卡牌、初始与普通遗物，以及 1000 金币作为启动资金。

> 存入仓库的物品会**还原为基础状态**（升级、附魔、道具等被清除），仓库里只存普通卡牌。

## 特性

- **持久仓库**：每个存档独立的仓库，跨局累计战利品，仓库金币上限 9999999。
- **携带系统**：开跑前自由搭配装备，卡牌与遗物占用共享的**背包容量**（默认 15 格）。
- **背包容量**：卡牌按稀有度占格（基础/普通 1、罕见 2、稀有 3、先古 4、其他 2），遗物统一占 2 格，卡牌与遗物共用同一个背包（默认 15 格）。仓库携带面板顶部显示「背包 X/15」容量条，用满即不能继续添加；携带超重时开仓/开跑会自动放下最重的物品，战备码导入也按剩余容量限制。可在「设置」中开关或调整。
- **搜打撤循环**：胜者通吃，败者一无所有——死亡或放弃会损失所有携带物品。
- **耐久系统**：每张卡牌与每件遗物都带**耐久**。每次撤离成功，带进局的每张牌 / 每件遗物耐久 -1；归 0 即损坏，不再入库。死亡或放弃直接损失全部携带物（开跑时已消耗，耐久不递减）。仓库瓦片右下角显示该组最低剩余耐久（琥珀色「耐久 n」），归 0 显示红色「耗尽」。可整体关闭（见「设置」）。
- **通关奖励**：每通关一次，额外发放该角色的整套初始牌组与初始遗物，可持续武装后续跑局。
- **仓库界面**：卡牌 / 遗物 / 药水三页签，每页独立的搜索 + 多选过滤（来源池、稀有度、类型、费用），大量物品也能流畅滚动的虚拟化网格，图标后台预加载。
- **商店系统**：仓库大厅右下角「商店」按钮打开商店，分**购买 / 出售**两页。库存每个现实日历日自动刷新一次，也可花金币手动刷新，详见「商店」一节。
- **撤离结算**：游戏结束界面新增「查看撤离结算」按钮，展示成功存入或失败损失的全部物品。
- **地图种子**：仓库大厅底部可设置自定义跑局种子——输入实时规范化（大写、O→0、I→1），附清空按钮；留空则随机，与基础游戏自定义界面一致。种子为仅本次会话、主机/单机所有的跑局参数，不随携带装备持久化；联机时全队沿用主机设定的种子。
- **单人 & 联机**：单人、多人主机均可从仓库出发；联机中每位玩家的装备按各自设置独立结算。
- **设置页**：最大携带牌数（0–20）与最大携带遗物数（0–6）滑条，以及一键重置。

## 商店

仓库大厅右下角的「商店」按钮打开商店（ESC 或左下角「仓库」按钮返回），与仓库共享同一份实时数据——金币、库存与携带草稿，右上角始终显示当前仓库金币。两个主 Tab：

- **购买**：卡牌 / 遗物 / 药水三个竖排分区。库存每个现实日历日首次打开时全量刷新一次；价格按原版基准价浮动后**冻结当天**（卡牌 / 药水 ±5%，遗物 ±15%），同一天内保持不变。买入价 = 当日冻结价 × 设置买入倍率（默认 ×2.0），买到的物品以满耐久入库。已售空的槽位保持空缺直到下次刷新。也可点击「刷新商店」付费重 roll 全部库存（50 → 每次 +50 → 封顶 250，每日重置）。
- **出售**：展示「仓库 − 携带」的可用物品，按份多选（左键选一件、右键减一件、Shift 全选 / 全不选），并支持搜索与多选过滤（来源池、稀有度、类型、费用、耐久度）。售价 = 原版确定性基准价 × 设置卖出比例（默认 50%）× 耐久系数（耐久 / 稀有度上限，向下取整，最低 1 金；药水与无耐久模式系数为 1）——磨损越重的装备越不值钱，出售时按最低耐久优先取出。

商店与仓库两页互斥：打开商店时隐藏仓库，关闭时恢复并刷新，保证金币与库存始终一致。

## 设置

- **背包容量**：总开关，默认开。开启后以**共享背包格数**限制携带，取代「最大携带牌数 / 遗物数」；关闭则回退到按类数量上限。切换需确认弹窗，跑局/大厅进行中禁止切换（同耐久开关）。
- **背包格数**：共享背包总格数，滑条 1–30，默认 15。
- **占格权重**：各稀有度卡牌与遗物的占格数（滑条最小值 1）——基础/普通 1、罕见 2、稀有 3、先古 4、其他 2（事件、衍生、状态、诅咒、任务与 mod 卡），遗物 2。
- **最大携带牌数**：0–20，默认 10（容量关闭时的备选上限）。
- **最大携带遗物数**：0–6，默认 3（容量关闭时的备选上限）。
- **悬停提示**：卡牌 / 遗物 / 药水瓦片悬停时是否显示原版提示框（默认开）。
- **耐久系统**：总开关，默认开。关闭后切换到一次性**无耐久仓库**（副本永不递减、不显示耐久）；重新开启时回到之前冻结的耐久仓库，无耐久仓库进度作废。
- **耐久上限**：决定**新入库**物品的耐久上限（只影响新入库，不追溯已有物品），各滑条范围 1–20——基础 5 / 普通 4 / 罕见 3 / 稀有 2 / 先古 1 / 其他 1（事件、衍生、状态、诅咒、任务与 mod 卡）/ 遗物 3。
- **商店买入倍率**：购买价格 = 当日冻结价 × 此倍率，滑条 ×1.0–×5.0，默认 ×2.0。
- **商店卖出比例**：出售价格 = 原版基准价 × 此比例（再乘耐久系数），滑条 10%–100%，默认 50%。
- **重置默认值**：一键恢复所有设置。

耐久开关切换需确认弹窗；跑局进行中或角色选择大厅打开时禁止切换（携带装备已暂存，无法收回）。设置保存于全局范围，所有存档共享。

## 兼容性

- **海克斯符文 mod**：首次进入仓库发放初始物品时，**不会**发放该 mod 的遗物。
- **联机大厅 mod（STS2-Game-Lobby）**：大厅建房表单新增「搜打撤」房间类型，创建的房间在房间列表显示「搜打撤」pill；房主与加入的客机都会被强制要求先配置携带，开跑后走完整的搜打撤注入 / 消耗 / 撤离链路。仅在本 mod 侧以反射打补丁，无编译期依赖；未安装联机大厅时完全无副作用。

## 调试指令

游戏内置开发控制台提供以下「搜打撤」指令（仅本机生效，不受设置页影响）：

```
extraction reset                                           # 重置仓库（带确认框）
extraction add <card|relic|potion|gold> <id|数量> [count]   # 向仓库添加
extraction remove <card|relic|potion|gold> <id|数量> [count] # 从仓库移除
```

- **`extraction reset`**：清空仓库并重新发放初始物品。会先弹出确认框；**跑局进行中或角色选择大厅中不可用**。
- **`extraction add`**：向仓库添加物品。`card` / `relic` / `potion` 以模型 ID 指定（大写下划线形式，如 `STRIKE`，支持 Tab 补全）；`gold` 直接填数量。`[count]` 省略时默认为 1，上限 999。添加走常规入库流程，物品会还原为基础状态。
- **`extraction remove`**：从仓库移除物品或金币。寻址方式同上，`[count]` 省略时默认为 1，上限 999。**跑局进行中或角色选择大厅中不可用**；移除后会同步清理携带中对应的物品，避免凭空复制。
